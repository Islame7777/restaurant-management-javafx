# 🍽️ Restaurant Management System

A desktop restaurant management application developed with JavaFX to streamline restaurant operations, including customer management, order processing, reservations, and menu administration.

## 🚀 Features

- Customer Management
- Order Processing
- Reservation Management
- Menu Administration
- Table Management
- User Authentication
- Database Integration

## 🛠 Technologies Used

### Frontend
- JavaFX
- FXML
- CSS

### Backend
- Java

### Database
- MySQL

### Architecture
- MVC (Model-View-Controller)
